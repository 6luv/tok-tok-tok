# DESIGN — 하루 기록 화면

상태: 2026-11-10 뉴모피즘 개편안(`feature/ui-redesign`). 동작 기준은 PRD.md이며, 이 문서는 화면의 모양과 상호작용만 정한다. 이전 안(그래파이트 + 호박색 채움 버튼, 플립 패널)은 git 이력에 남아 있다.

## 방향

사용자가 제시한 레퍼런스(Pinterest ‘Neumorphism vibe’ 위젯 키트)와 비슷한 뉴모피즘 시계·알람 UI들을 참고했다. 이 레퍼런스들의 주제나 배치는 가져오지 않고 아래 특징만 따른다.

| 항목 | 내용 |
|---|---|
| 제품 | 뒷면 탭·단축어·버튼으로 지금 시각을 남기고, 직접 정한 하루 시작 시간으로 묶어 보는 개인 기록 앱 |
| 성격 | 조용함, 정확함, 손끝으로 누르는 물건 같음 |
| 세계 | 회색 한 덩어리로 깎아 만든 탁상시계. 튀어나온 버튼과 파인 숫자 창 |
| 핵심 장면 | ① 기록 목록을 담은 파인 판과 그 안에서 튀어나온 최신 행(얇은 둥근 글꼴 숫자) ② 헤더 카드 안의 파인 하루 눈금 |
| 고유 요소 | 눈금. 가장 최근 기록은 하루 눈금과 최신 행에 같은 메인 색 눈금으로 표시한다 |

원칙:
- 깊이는 색이 아니라 그림자로만 만든다. 밝은 그림자는 위·왼쪽, 어두운 그림자는 아래·오른쪽이다.
- 누를 수 있는 것은 튀어나와 있고(extruded), 누르면 파인다(inset). 정보를 담는 창은 파여 있다.
- 색은 사용자가 고른 메인 색 하나(기본 호박)이며 면을 채우지 않는다. 최신 기록 눈금(`tick`)과 앱 tint(동작 글자·시스템 버튼)에만 쓴다.
- 뉴모피즘은 대비가 약해지기 쉬우므로 글자는 진하게 두고 모든 글자 대비를 4.5:1 이상으로 맞춘다.

## 화면 모드

설정의 ‘화면 모드’에서 다크·라이트를 고른다. 기본은 다크다(Q11 결정 2026-11-10). 선택은 바로 적용되고 기록과 무관하다. 저장은 `UserDefaults` 키 `toktok.appearance`(`dark`/`light`)이며, 하루 경계 설정 파일과는 따로 둔다. 모든 색 토큰은 두 벌이다. Info.plist의 다크 고정(`UIUserInterfaceStyle=Dark`)은 제거했다.

앱 시작 화면(launch screen)과 앱 안 로딩 화면은 기기·앱 화면 모드와 관계없이 다크다(사용자 요청 2026-11-11: 검은 화면 대신, 다크 기본). 시작 화면은 `Config/Info.plist`의 `UILaunchScreen` › `UIColorName` = `LaunchBackground`(#1B1A18 한 가지, 앱 아이콘 바탕색)만 보인다. 시계 그림은 넣지 않는다: 사용자 기기에서 시작·로딩 화면 그림이 깨져 보인다는 보고가 있었다(2026-11-11, 이전 `LaunchArt` 440×956 그림 제거). 기종마다 시작 화면 그림의 배치·확대가 달라서라는 것은 추정 원인이며 실기기 재현은 확인하지 않았다. 이어서 앱 안 로딩 화면(`LaunchSplashView`)이 같은 바탕색 위에 자명종을 벡터(`LaunchClock`, Canvas)로 그린다. 앱 아이콘 1024 구도(중심 700·800, 왼쪽으로 15°, 1.38배, 소리 호·눈금 4개·10시 10분, 아이보리 #F2EBD9 선)를 화면 너비 크기의 정사각형에 그려 화면 맨 아래에 붙이므로, 어떤 iPhone에서도 선명하고 비율이 같다. 위쪽(안전 영역 아래 40, 왼쪽 28)에 ‘Tok Tok Tok’(띄어쓰기, 사용자 요청 2026-11-11. 앱 이름 표기는 TokTokTok 유지, 40pt 둥근 글꼴 500, 아이보리, 좁으면 70%까지 줄임)과 ‘뒷면을 톡톡톡, 지금 시각을 남겨요’(`.subheadline`, #BDB5A3)를 붙인다. 1.5초 보인 뒤 0.45초 동안 흐려지며 하루 화면을 드러낸다(모션 감소면 바로 사라짐). 하루 화면은 그동안 뒤에서 자료를 읽고 VoiceOver에서는 숨긴다. 로딩 화면은 VoiceOver에서 ‘TokTokTok 불러오는 중’ 한 요소로 읽힌다. 앱 기본 화면 모드도 다크다(Q11).

## 화면 구조

위에서 아래로 헤더 카드, 기록 목록, 하단 기록 버튼 순서다. 영역과 기록 사이에는 선을 두지 않고 그림자와 간격으로 나눈다. 헤더 카드 안 제목과 기록 버튼은 화면 왼쪽 20pt에서 시작한다. 기록 시각은 판 여백과 눈금 자리를 더해 40pt에서 시작한다(바깥 8 + 판 안쪽 8 + 행 안쪽 24).

 │ └──────────────────────────────────┘ │

### 헤더 카드

- 좌우 8 바깥 여백, 안쪽 12(합 20 = 기록 창 시작선), 모서리 24, 튀어나온 면(깊이 6).
- 기록일 제목: `.title2` 400, 본문색, `isHeader`.
- 구간 문구는 따로 두지 않고 하루 눈금 양끝 라벨로 보여 준다. VoiceOver는 제목과 함께 “11월 10일 기록, 기록 구간 …”으로 읽는다.
- 설정: 원형 튀어나온 버튼 44×44pt, 톱니 17pt 보조색. 누르면 파인다.
- 제목 줄(제목과 설정 버튼 세로 가운데 정렬)과 하루 눈금 사이 12.

### 하루 눈금

이미 있는 정보(현재 기록일 구간, 각 기록 시각)를 그림으로 옮긴 것이며 새 기능이나 통계가 아니다.

- 헤더 카드 안의 파인 홈(모서리 12 = 카드 24 − 안쪽 12, 깊이 3, 안쪽 좌우 12·위 12·아래 8)에 담는다.
- 가로 전체가 기록일 구간 하나다. 시작은 사용자가 정한 경계이고, 자정이 아니다. 서머타임 등으로 구간이 23·25시간이면 실제 길이로 나눈다.
- 매시 짧은 눈금(3pt), 6시간마다 긴 눈금(6pt).
- 라벨 세 개(11pt 둥근 글꼴 500 같은 폭 숫자): 왼쪽 끝 구간 시작 `MM/dd HH:mm`, 오른쪽 끝 구간 끝 `MM/dd HH:mm`(보조색), 가운데 구간 절반 시각 `HH:mm`(흐린색).
- 지난 부분 기준선은 보조색, 남은 부분은 흐린 색. 지금 위치는 본문색 점(5pt), 1분마다 갱신.
- 기록마다 세로선(본문색 75%, 1.5pt). 가장 최근 기록만 `tick` 호박색 2pt.
- 같은 정보가 구간 문구와 블록 목록에 있으므로 VoiceOver에서는 숨긴다.

### 기록 목록과 행

사용자 결정(2026-11-10, HTML 시안 H): 시각 창만 따로 튀어나오거나 파이면 날짜와 따로 노는 문제가 있어, 목록 전체를 파인 판 하나에 담고 행 하나가 시각과 날짜를 함께 담는다.

- 판: 화면 좌우 바깥 8, 안쪽 8, 모서리 24(= 행 16 + 안쪽 8), 파인 홈(깊이 3). 목록 콘텐츠의 가로 전체 폭을 쓴다(R05). 행 사이 2pt, 선 없음. 기록이 없으면 판을 그리지 않는다.
- 판 모양은 스크롤 밖에 고정하고 스크롤되는 행을 판의 둥근 모서리로 자른다(`insetPanel`: 판 면은 뒤, 안쪽 그림자는 위). 중간까지 스크롤해도 위아래가 네모로 잘리지 않는다(사용자 지적 2026-11-10). 기록이 적으면 판은 내용 높이만큼, 많으면 기록 버튼 위까지 채우고 판 안에서 스크롤한다.
- 행: 안쪽 왼쪽 24(눈금 자리를 모든 행에 둬 시각 시작선을 맞춤)·오른쪽 16·상하 10, 모서리 16, 최소 높이 44. 고정 높이를 두지 않는다.
- 가장 최근 행만 판 안에서 튀어나온 면(깊이 5)이고, 행 안쪽 왼쪽(10)에 3pt `tick` 호박색 알약 눈금(위아래 18 안쪽)이 있다. 나머지 행은 판 면 그대로다.
- 시각 숫자: 32pt 기준 `@ScaledMetric`(largeTitle 비례), SF Pro Rounded 300(얇게), 같은 폭 숫자. `HH:mm`은 본문색, `:ss`는 보조색. `00:00:00` 자리표시로 폭을 맞춘다.
- 날짜: 오른쪽 끝 두 줄, 오른쪽 정렬. 위 ‘10일’(`.title3`, 본문색), 아래 ‘11월 · 화’(`.caption`, 흐린색, 요일 포함). 접근성 글씨 크기(AX1 이상)에서는 시각 아래로 내려가 왼쪽 정렬된다.
- 날짜는 같은 달력 날짜 묶음의 맨 위 행에만 보인다(`RecordBlock.showsDate`). 경계가 자정이 아니면 한 기록일에 두 날짜가 섞이므로(예: 04:00 경계에서 00:42 기록은 다음 날짜), 날짜가 바뀌는 첫 행에 다시 표시한다. 날짜를 숨긴 행도 VoiceOver는 ‘11월 11일 오전 12시 42분 10초, 시간 기록’처럼 날짜와 시간을 함께 읽는다.

쌓기 순서(Q04, 사용자 결정 2026-11-10): 위에서 아래로 최신 → 과거이다. 목록은 헤더 바로 아래 위쪽에 붙고, 첫 기록도 맨 위에 놓인다. 위쪽에 빈 공간을 두지 않는다(이전의 ‘목록 바닥에서부터 쌓기’는 폐기).

블록의 날짜에는 실행 시점의 ‘오늘 날짜’를 일괄 채우지 않는다. 각 기록의 실제 달력 날짜를 표시한다. 하루 헤더와 날짜가 다른 것은 정상이다.

### 기록 하나 지우기(사용자 결정 2026-11-11, Q06)

- 기록 행을 오른쪽으로 조금 밀면 왼쪽에 휴지통 버튼(튀어나온 원 44pt, 메인 색 아이콘)이 나오고 72pt 열린 채 멈춘다. 휴지통을 누르면 지운다.
- 180pt 이상 끝까지 밀면 바로 지운다. 왼쪽으로 다시 밀거나 행을 누르면 닫힌다. 덜 예민하게(사용자 요청 2026-11-11): 24pt 이상 움직이고 가로가 세로의 2배를 넘게 시작한 드래그만 반응하며, 시작 거리 24를 뺀 뒤 손가락 이동의 0.8배만 따라간다. 위의 72(열림)·180(즉시 삭제)은 행의 최종 이동 거리이므로, 손가락으로는 닫힌 행에서 약 249pt를 밀어야 바로 지워지고(열린 행은 약 159pt 더), 약 69pt 이상 밀면 열린 채 멈춘다. 방향은 사용자 요청(2026-11-11)으로 왼쪽 → 오른쪽 밀기로 바꿨다. 하루 화면은 첫 화면이라 화면 가장자리 뒤로 가기 제스처와 겹치지 않는다. 한 번에 한 행만 열린다.
- 밀린 동안에만 행 모양(모서리 16)으로 잘라 판 밖으로 삐져나오지 않게 한다.
- 밀수록 행 뒤 왼쪽에서 메인 색(`tick`) 그라데이션이 짙어진다(투명 → 15%+60%×진행률). 놓으면 지워지는 거리(180)를 넘으면 휴지통이 메인 색으로 채워지고(채운 아이콘, 1.1배) ‘놓으면 지워짐’을 알린다(사용자 요청 2026-11-11).
- 세로 스크롤을 막지 않도록 드래그 시작 방향이 가로일 때만 반응하고, 시작 방향을 끝까지 유지한다. VoiceOver는 ‘삭제’ 동작으로 지운다.
- 화면 스냅샷에 있던 그 기록만, 저장소 내용이 같을 때만 지운다. 확인 창과 되돌리기는 없다. 지우지 못하거나 이미 없으면 버튼 위 알림 상자와 VoiceOver 음성으로 알린다.

### 스크롤

목록이 길어지면 스크롤한다. 최초 진입은 최신 기록을 보여준다. 사용자가 다른 위치를 읽는 동안 외부 Intent 기록이 들어오면 스크롤 위치를 유지하고, 목록 위쪽에 ‘새 기록 N개’ 보조 버튼(위쪽 화살표, 튀어나온 작은 알약)을 띄운다. 앱 내 기록 버튼으로 추가한 경우 새 블록으로 이동한다. 화면 전체를 뒤집는 방식으로 시각 순서와 VoiceOver 탐색 순서가 달라지지 않게 한다.

### 하단 기록 버튼

- 좌우 20 여백의 전체 폭, 최소 높이 64, 모서리 20 둥근 사각형(알약 아님, 헤더 카드와 같은 계열), 튀어나온 면(깊이 7). 색을 채우지 않는다.
- 내용: 손가락 탭 아이콘(18pt, 보조색)과 ‘현재 시간 기록’(`.body` 500, 본문색).
- 누르면 파인 홈으로 바뀐다(150ms). 모션 감소 설정에서는 애니메이션 없이 바로 바뀐다.
- 저장 중에는 진행 표시와 ‘저장 중…’.
- 버튼 위에 저장 결과를 보인다(아래 ‘상태별 표현’).

| 기록 없음 | 기록 목록과 같은 파인 판(모서리 24) 안에 비어 있는 튀어나온 시각 창 ‘--:--:--’(흐린색 60%, VoiceOver 숨김), ‘기록한 순간이 여기에 쌓여요’(`.body` 500), ‘아래 버튼을 누르거나 뒷면을 세 번 톡톡톡 쳐 보세요’(보조색), ‘뒷면 탭 연결하기’ 보조 버튼 |
| 불러오는 중 | 보조색 진행 표시 ‘불러오는 중’. 빈 데이터로 단정하지 않음 |
| 저장 중 | 기록 버튼에 진행 표시. 연속 입력 정책에 따라 독립 요청 처리 |
| 저장 성공 | 실제 저장 완료한 블록 추가. 화면 위쪽에 기록 토스트(`RecordToastView`: 튀어나온 카드 모서리 20, 메인 색 눈금, 시각 `.title2` 300 + 초 보조색, ‘M월 d일 기록했어요’, 체크 아이콘)가 위에서 살짝 내려와 2초 뒤 사라짐(누르면 바로 닫힘). 소리는 내지 않고 진동 한 번 |
| 저장 실패 | 버튼 위 튀어나온 알림 상자(모서리 24, 안쪽 20): 경고 아이콘, ‘기록을 저장하지 못했어요’, 원래 시각 안내, ‘다시 시도’(보조 버튼)·‘닫기’. 성공 블록을 남기지 않음 |
| 기타 기록 오류 | 같은 알림 상자에 오류 문구와 ‘닫기’ |
| 조회 실패 | 오류 문구, ‘기존 기록이 삭제된 것은 아니에요’, ‘다시 시도’ 보조 버튼 |
| 읽지 못한 파일 | 목록 위에 개수와 ‘삭제하지 않고 보관 중’ 안내(보조색) |
| 하루 전환 | 새 구간으로 재조회. 자정이 아니라 설정한 경계에서 갱신 |

성공·실패는 색이 아니라 아이콘과 문구로 전달한다. 오류에 빨간색을 쓰지 않는다.

### 기록 완료 피드백(사용자 결정 2026-11-10, Q07)

- 소리(2026-11-11 다시 결정): 저장 확인 뒤 짧은 마림바 소리 한 번(`record-sound.wav`, 프로젝트에서 만든 0.45초 합성음). 기기 무음 모드에서는 iOS가 소리를 내지 않는다(진동은 진동 스위치·기기 설정을 따른다). 설정 ‘기록할 때 소리’로 끌 수 있다(기본 켜짐, `toktok.sound`). 처음엔 새벽 기록을 걱정해 소리를 뺐으나, 사용자가 끄기 스위치를 두는 조건으로 다시 넣기로 했다. 아이폰 기본 문자음(노트)은 Apple 소리라 쓰지 않았다.
- 진동: 저장이 확인된 뒤 기기 기본 진동 한 번(사용자 결정 2026-11-11). 설정 ‘진동’ 토글로 끌 수 있다. 앱 안 버튼·뒷면 탭·단축어 모두 같다. Audio Toolbox `kSystemSoundID_Vibrate`(공개 상수)를 쓰며, 기기 진동 설정이 꺼져 있으면 울리지 않는다. 앱이 화면에 없을 때 울리는지는 실기기 확인 대상이고 background 모드는 추가하지 않는다.
- 단축어·뒷면 탭 결과: 앱은 결과 토스트를 띄우지 않는다(사용자 결정 2026-11-10). 실행 중이라는 iOS 자체 표시가 이미 보이기 때문이다. 기록 실패는 Intent 오류 문구로 알린다. 토스트(`RecordToastView`)는 앱 안 기록 버튼에만 쓴다.

## 첫 실행 경계 설정

- 제목 ‘하루가 시작되는 시간을 정해 주세요’(`.title2` 400)와 설명(`.subheadline`, 보조색).
- 시·분 휠 선택기와 실제 구간 예시를 튀어나온 상자(모서리 28, 안쪽 20) 하나에 담는다.
- 하단: 흐린 안내 ‘값을 고른 뒤 아래 버튼을 눌러야 저장돼요’와 주 버튼 ‘이 시간으로 시작 · HH:MM’(기록 버튼과 같은 알약). 선택기의 처음 위치는 미리보기일 뿐 기본값이 아니다(Q01).

## 설정과 연결 안내

설정 화면 맨 위에는 시스템 탐색 막대 대신 ‘닫기 · 설정’ 줄을 둔다(스크롤해도 고정). ‘닫기’는 위 막대 버튼(`HeaderButtonStyle`: 모서리 12 둥근 사각형, 최소 44×44, 튀어나오고 누르면 파임)이다. ‘적용’ 버튼은 없앴다(2026-11-11): 메인 색·화면 모드·진동은 바로 적용되고, 하루 시작 시간만 카드 안에서 저장한다. 시간을 바꾸면 카드 안에 ‘되돌리기’와 ‘HH:MM로 저장’(메인 색 글자)이 나타나고, 저장하면 화면은 그대로 둔 채 버튼이 사라진다. 저장하지 않고 닫으면 시간 변경은 버린다. 하위 화면(뒷면 탭 연결·개인정보)도 같은 위 막대(`neuNavigation`: 왼쪽 뒤로 버튼 ‹ + 가운데 제목 최대 2줄, 접근성 큰 글씨에서는 제목이 뒤로 버튼 아래로)를 쓰고, 전환 중이 아닐 때 화면 왼쪽 가장자리를 밀어 뒤로 가기는 유지한다(`UINavigationController.interactivePopGestureRecognizer` 위임, 공개 API).

설정·뒷면 탭 연결·개인정보 화면은 시스템 `List` 대신 같은 뉴모피즘 카드를 쓴다(`NeuPage`·`NeuSection`). 화면 좌우 20, 묶음 사이 28. 묶음마다 머리글(`.footnote` 500, 보조색) → 튀어나온 카드(안쪽 16, 모서리 20, 깊이 5, 내용 사이 12) → 꼬리말(`.footnote`, 흐린색). 행 목록 카드(뒷면 탭 연결·개인정보와 데이터, 오늘 기록 지우기)는 `compact`: 위아래 안쪽 4, 행 사이 0으로 행 높이 44가 간격을 맡는다(사용자 요청 2026-11-11). 설정 묶음 순서: 하루 시작 시간 → 메인 색 → 화면 모드 → 연결·개인정보 → 기록. 연결·개인정보 카드 꼬리말: ‘뒷면 탭 기록은 화면이 켜져 있을 때만 돼요’(사용자 요청 2026-11-11). 다음 화면으로 가는 행은 높이 44에 오른쪽 꺾쇠(13pt, 흐린색), 행 사이는 가는 선. 제목은 인라인 표시. 위 막대의 ‘닫기’·‘뒤로’ 버튼 글자는 본문색이고, 카드 안 동작 글자(‘단축어 앱 열기’·‘HH:MM로 저장’ 등)는 앱 tint(메인 색)를 쓴다.

- 글은 짧게: 설명은 한 줄(문장 하나는 마침표 없이), 긴 주의사항도 항목당 한두 문장으로 줄인다. 화면이 켜져 있을 때만 기록된다는 안내·iOS 알림·기록 시각 차이 안내는 ‘뒷면 탭 연결’ 화면의 ‘알아 두세요’에 남긴다.
- ‘하루 시작 시간’: 시·분 선택기만 둔다(사용자 요청 2026-11-10: ‘현재 설정’ 행, ‘지금 구간 …’ 예시, 꼬리말 제거). 구간 예시는 첫 실행 화면에만 보인다(`BoundaryPicker(showsExample:)`). 시간을 바꾸면 카드 안에 ‘되돌리기’·‘HH:MM로 저장’이 나타난다. 저장 실패 시 이전 설정을 유지하고 오류를 카드 안에 보인다. 시간대 안내(Q03)는 ‘개인정보와 데이터’ 화면에 있다.
- ‘기록’(설정 맨 아래, Q06 사용자 결정 2026-11-10): ‘오늘 기록 지우기’ 행(휴지통 아이콘, 메인 색 글자 500, 높이 44, 사용자 요청 2026-11-11). 꼬리말은 두지 않는다. 누르면 앱 확인 창(아래)이 뜬다. 대상은 확인 창을 열 때 고정한 기록일 제목과 그때 보이던 기록 배열뿐이다. 창이 열린 동안 목록이 바뀌어도 제목·개수·삭제 대상은 바뀌지 않으며, 확인 뒤 새로 들어온 기록과 읽지 못한 파일은 지우지 않는다(Codex 검증 반영 2026-11-11). 기록이 없으면 행을 끄고 흐린색으로 둔다. 일부를 확인하지 못해 남기면 경고 아이콘과 ‘N개를 지웠어요. M개는 확인하지 못해 남겨 뒀어요.’, 삭제 자체가 실패하면 ‘기록을 지우지 못했어요. 남은 기록은 그대로예요.’ 빨간색은 쓰지 않는다.
- 지우기 확인 창(사용자 요청 2026-11-11, HTML 시안): 시스템 대화상자 대신 화면 가운데 튀어나온 카드(모서리 28, 깊이 7, 안쪽 좌우 20·위 24·아래 20, 화면 좌우 28, 최대 폭 400). 뒤는 검정 35%로 어둡게, 바깥을 누르면 취소. 위에서부터 파인 원(56) 안 휴지통(메인 색) → 제목 ‘11월 10일 기록을 지울까요?’(`.title3` 500, 가운데) → ‘지운 기록은 되돌릴 수 없어요’(`.subheadline` 보조색) → 버튼 두 개 나란히(사이 12): ‘취소’(본문색)·‘N개 지우기’(메인 색). 버튼은 튀어나온 둥근 사각형(모서리 18, 높이 52, `DialogButtonStyle`), 누르면 파인다. 나타남·사라짐은 투명도 0.2초, 모션 감소면 바로. VoiceOver는 모달로 읽고 두 손가락 문지르기(escape)로 취소한다.
- ‘화면 모드’: 다크·라이트 뉴모피즘 분할 선택(`NeuSegmented`): 파인 알약 홈(안쪽 4) 안에서 고른 칸만 튀어나온다. 칸 높이 40, 고른 칸 글자 본문색·나머지 보조색. 바로 적용되고, 안내 문구는 두지 않는다(사용자 요청 2026-11-10 ‘바로 적용돼요’ 제거).
- ‘소리와 진동’(2026-11-11 ‘진동’에서 바꿈): ‘기록할 때 소리’와 ‘기록할 때 진동’ 두 줄(가는 선으로 나눔), 각각 뉴모피즘 스위치(`NeuToggleStyle`: 파인 알약 홈 56×32 안에서 튀어나온 원 24가 움직임, 켜지면 오른쪽·홈을 메인 색 `tick`으로 불투명하게 채움). 기본 켜짐, `UserDefaults` 키 `toktok.vibration`. 끄면 앱이 진동 명령을 보내지 않는다. 기기 설정이 진동을 막으면 앱이 무시할 수 없다(사용자 요청 2026-11-11 “설정과 상관없이 울리게”는 iOS 제약으로 불가). VoiceOver는 스위치로 읽고 ‘켜짐/꺼짐’ 값을 알린다. 카드는 ‘뒷면 탭 연결’ 카드와 같은 촘촘한 여백(위아래 4, 스위치 줄 높이 44)이고, 같은 카드 안 스위치 아래에 가는 선 → 흐린 안내 ‘무음 모드에서는 소리가 나지 않아요’·‘진동이 울리지 않으면 iPhone 설정에서 확인해 주세요’ → 두 줄(왼쪽 경로 보조색, 오른쪽 맞출 값 메인 색): ‘사운드 및 햅틱 › 햅틱 — 항상 재생’, ‘손쉬운 사용 › 터치 › 진동 — 켬’. 큰 글씨에서는 값이 경로 아래로 내려간다(사용자 요청 2026-11-11).
- ‘메인 색’: 원형 견본 5개(호박·산호·세이지·하늘·라벤더)와 이름(`.caption`). 견본 24pt 원 + 안쪽 10, 고르지 않은 것은 튀어나오고 고른 것은 파인다(깊이 3). 칸마다 터치 영역 44 이상. VoiceOver는 색 이름과 ‘선택됨’을 읽는다. 바로 적용되며 `UserDefaults` 키 `toktok.accent`에 저장한다. 기본 호박.
- ‘뒷면 탭 연결’(2026-11-11 다시 정리: 사용자 기기에서 레이아웃이 깨졌다는 보고 후, 줄바꿈 칩과 번호 옆 들여쓰기를 없애 세로로만 늘어나게 함): 한 줄 소개 → 단계 카드 3개 → ‘알아 두세요’.
  - 단계 카드: 튀어나온 카드(안쪽 16, 모서리 20, 깊이 5). 위 줄에 번호 원 32pt(튀어나옴, 완료면 파이고 메인 색 체크)와 제목(`.body` 500), 아래에 내용이 카드 전체 폭을 쓴다.
  - 1 단축어 만들기: 작은 순서 목록 4줄(새 단축어 열기 → ‘동작 추가’에서 TokTokTok 검색 → ‘현재 시간 기록’ 넣기 → 이름 ‘톡톡톡’으로 완료)과 전체 폭 ‘단축어 앱 열기’ 버튼(`shortcuts://create-shortcut`). 공유 링크가 있으면 ‘받기’ 2줄과 받기 버튼. ‘동작 미리 보기’(`ShortcutsLink`)는 단축어 앱에서 자동 단축어를 지우면 버튼이 사라져 헷갈려서 제거했다.
  - 2 뒷면 탭에 연결: 1단계와 같은 번호 목록 6줄(설정 앱 열기 → 손쉬운 사용 → 터치 → 뒷면 탭 → 세 번 탭 → ‘톡톡톡’ 선택). 안내는 ‘세 번 탭’ 기준이다(사용자 결정 2026-11-11, 앱 이름 ‘톡톡톡’과 맞춤). 앱이 설정 화면을 대신 열 수 없다는 안내.
  - 3 시험하기: 파인 홈 안에 마지막 단축어 기록 시각(또는 ‘아직 단축어 기록이 없어요’)과 전체 폭 ‘다시 확인’ 버튼. 기록이 있으면 번호 원이 체크로 바뀐다. 앱으로 돌아오면 자동으로 다시 확인한다.
  - 연결 확인 후(최근 2주 안에 단축어 기록이 있으면, 2026-11-11): 맨 위에 요약 카드(파인 원 안 메인 색 체크, ‘뒷면 탭이 연결됐어요’, ‘뒷면을 세 번 톡톡톡 치면 기록돼요’, 파인 홈 안 마지막 단축어 기록 시각, ‘다시 확인’)를 두고 단계 카드 1~3은 접는다. ‘연결 방법 다시 보기 / 접기’ 보조 버튼으로 펼친다.
  - 알아 두세요: 아이콘(흐린색 14pt) + 한 줄씩. 기록 시각 차이, iOS 실행 중 표시, 화면이 켜져 있을 때만 기록됨(Siri 대안은 잠금 상태 실기기 미동작으로 뺌, 사용자 결정 2026-11-11), 앱 안 버튼.
- ‘알아 두세요’ 안내 문단은 보조색 `.subheadline`.

### 깊이·간격·모서리·모션

- 튀어나온 면: 바탕색 면 + 어두운 그림자(아래·오른쪽, 거리 d, 흐림 1.6d) + 밝은 그림자(위·왼쪽, 같은 값). d는 헤더 카드 6, 기록 버튼 7, 최신 기록 행 5, 작은 버튼 4.
- 파인 홈: `well` 면 안쪽에 어두운 그림자(아래·오른쪽)와 밝은 그림자(위·왼쪽)를 흐려 넣는다. 깊이 3~4.
- 간격은 4pt 격자: 4, 8, 12, 16, 20, 24, 28, 32. 화면 좌우 시작선 20(헤더 카드는 바깥 8 + 안쪽 12).
- 모서리: 눈금 홈 12, 기록 행 16, 기록 목록 판 24, 설정 카드·주 버튼(기록·첫 실행) 20, 헤더 카드·알림 상자 24, 첫 실행 상자 28. 보조 버튼(작은 버튼)만 알약, 설정 버튼은 원.
- 곡선 하나 `cubic-bezier(0.22, 1, 0.36, 1)`. 버튼 누름 150ms(튀어나옴 → 파임), 새 블록으로 스크롤 350ms, 블록 삽입은 투명도 전환.
- 모션 감소 설정에서는 스크롤 애니메이션, 삽입 전환, 버튼 누름 애니메이션을 없앤다. 반복 애니메이션·번쩍임·자동 소리는 넣지 않는다. 소리·햅틱 여부는 Q07에서 결정한다.
