# 실기기 점검표

시뮬레이터로는 확인할 수 없는 항목만 모았다. 최신 `main`을 Xcode로 iPhone에 설치한 뒤 위에서부터 차례로 확인한다. 결과는 칸에 적고, 끝나면 [TEST_RESULTS.md](TEST_RESULTS.md)에 새 기록 번호로 옮긴다. 번들 ID·기기 고유 번호·개인 기록 시각은 적지 않는다.

## 준비

- [ ] 기종 / iOS 버전 기록: ____________
- [ ] 설정 › 사운드 및 햅틱 › 햅틱: ‘항상 재생’ / 손쉬운 사용 › 터치 › 진동: 켬
- [ ] 단축어 ‘톡톡톡’(TokTokTok › 현재 시간 기록)을 뒷면 탭 › 세 번 탭에 연결

## 1. 앱 안 기록

| 확인 | 기대 | 결과 |
|---|---|---|
| ‘현재 시간 기록’ 누르기 | 목록 맨 위에 새 기록, 위쪽 토스트 2초 뒤 사라짐, 진동 한 번 | |
| 소리 모드·무음 모드 각각 | 두 모드 모두 진동 한 번, 소리 없음 | |
| 설정 › 진동 끔 → 기록 | 진동 없음, 토스트는 표시 | |
| 연속으로 빠르게 3번 | 기록 3개, 진동 3번 | |

## 2. 뒷면 탭 기록

| 상태 | 기대 | 결과 |
|---|---|---|
| 화면 켜짐·잠금 해제, 다른 앱 사용 중 | iOS 실행 중 표시, 앱 토스트 없음, 진동 한 번, 앱을 열면 기록 있음 | |
| 화면 켜짐·잠금 화면 | 위와 같음(잠금 상태 저장 가능 여부 확인) | |
| 화면 꺼짐 | 기록 안 됨 예상(TS-007). 바뀌었는지만 확인 | |
| 화면 꺼짐에서 Siri “TokTokTok 기록” | 기록 여부 | |
| 앱 강제 종료 후 뒷면 탭 | 기록 여부 | |

## 3. 뒷면 탭 연결 화면

| 확인 | 기대 | 결과 |
|---|---|---|
| 기록 전(단축어 기록 없음) | 단계 카드 1~3이 펼쳐져 있음 | |
| ‘단축어 앱 열기’ | 단축어 앱의 새 단축어 화면이 열림 | |
| 뒷면 탭 후 이 화면으로 돌아오기 | 맨 위 ‘뒷면 탭이 연결됐어요’ 요약, 마지막 시각 표시, 단계는 접힘 | |
| ‘연결 방법 다시 보기’ | 단계가 펼쳐지고 ‘접기’로 바뀜 | |

## 4. 기록 지우기

| 확인 | 기대 | 결과 |
|---|---|---|
| 기록 행을 왼쪽으로 조금 밀기 | 오른쪽에 휴지통 버튼, 행이 열린 채 멈춤 | |
| 휴지통 누르기 | 그 기록만 사라짐 | |
| 끝까지 밀기 | 바로 사라짐 | |
| 열린 행을 누르거나 오른쪽으로 밀기 | 닫힘 | |
| 목록을 위아래로 스크롤 | 스크롤 중에 행이 옆으로 밀리거나 지워지지 않음 | |
| 설정 › ‘오늘 기록 지우기’ | 확인 창 뒤 오늘 기록 전체 삭제 | |

## 5. 설정

| 확인 | 기대 | 결과 |
|---|---|---|
| 하루 시작 시간 바꾸기 | 카드 안에 ‘되돌리기’·‘HH:MM로 저장’ 표시 | |
| 저장 | 버튼이 사라지고 화면 유지, 하루 화면 구간이 새 기준으로 바뀜 | |
| 되돌리기 | 원래 시간으로 돌아가고 버튼 사라짐 | |
| 바꾼 뒤 저장 없이 ‘닫기’ | 시간 변경 버려짐 | |
| 메인 색·화면 모드 바꾸기 | 바로 적용(눈금·스위치·버튼 색) | |
| 진동 스위치 | 켜짐/꺼짐 표시, 아래 안내 두 줄 | |

## 6. 화면·접근성

| 확인 | 기대 | 결과 |
|---|---|---|
| 앱 시작 순간 | 흰색·검은색 깜빡임 없이 바탕색(라이트 회색·다크 짙은 회색) | |
| 기록 없는 날 | 빈 시각 창·안내·‘뒷면 탭 연결하기’ 버튼 | |
| 목록을 중간까지 스크롤 | 판 위아래가 둥글게 잘림(네모로 잘리지 않음) | |
| 설정 › 손쉬운 사용 › 디스플레이 및 텍스트 크기 › 더 큰 텍스트 최대 | 하루 화면·설정·연결 화면에서 잘림·겹침 없음 | |
| VoiceOver: 기록 행 | ‘11월 1일 오전 3시 15분 8초, 시간 기록’처럼 날짜·시간 함께 읽음, ‘삭제’ 동작 있음 | |
| VoiceOver: 진동 스위치 | 스위치로 읽고 켜짐/꺼짐 알림 | |
| 동작 줄이기 켬 | 토스트·스크롤·버튼 애니메이션 없이 바로 바뀜 | |

## 아직 확인할 수 없는 기종

- iPhone Duo: Xcode에 기종이 없고 공식 사양이 나오지 않았다(R-023). 실기기가 생기면 6번 항목을 확인한다.
