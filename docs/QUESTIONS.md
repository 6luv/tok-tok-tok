추가 잠정 결정(구현 중 발생):

- 저장 실패 후 앱 내 ‘다시 시도’는 새 시각이 아니라 실패한 기록의 원래 시각·작업 ID로 저장한다. 단축어 실행의 저장 실패는 재시도 대상을 보관하지 않고 오류로 알린다.
- 연속 탭은 각각 독립 기록으로 처리하며 버튼을 잠그지 않는다.
- 저장소는 SwiftData 대신 기록 1건 = JSON 파일 1개 방식(PRD의 SwiftData는 ‘제안’). Linux에서 자동 테스트 가능, 공유 파일 수정이 없어 동시 쓰기 손실이 없다. 기록이 수만 건으로 늘면 월 단위 디렉터리 조회 성능을 재검토한다.
