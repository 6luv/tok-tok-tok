## 홍보 이미지 (6.9형, 1320×2868, PNG) — 올릴 것

위에 안내 문구, 아래에 실제 앱 화면을 둥근 모서리·뉴모피즘 그림자로 얹었다. 핵심 단어 하나만 메인 색(호박)으로 강조, 글꼴은 앱과 같은 SF Pro Rounded. 올리는 순서:

1. `01-backtap.png` — **뒷면 세 번 톡톡톡** / 지금 시각이 바로 기록돼요(다크)
2. `02-my-day.png` — **내가 정하는 하루** / 새벽 기록도 어제와 함께 모아 봐요(라이트)
3. `03-connect.png` — **한 번만 연결하면 끝** / 뒷면 탭 연결을 단계별로 안내해요(라이트)
4. `04-settings.png` — **내 취향대로 조용하게** / 소리·진동, 다크·라이트, 메인 색 5가지(다크)
5. `05-start.png` — **자정이 아니어도 괜찮아요** / 하루가 시작되는 시간을 직접 골라요(다크)

만드는 방법: 아래 원본 스크린숏을 AppKit으로 합성(스크립트는 저장소 밖에서 실행, 결과 이미지만 보관).

## 원본 스크린숏 (6.9형, 1320×2868, PNG)

iPhone 17 Pro Max 시뮬레이터(iOS 26.5)에서 실제 앱 화면을 찍었다. 기록은 예시 데이터이며 개인 기록이 아니다. 올리는 순서를 추천한다.

1. `01-day-dark.png` — 하루 화면(다크): 하루 눈금과 기록 목록
2. `02-day-light.png` — 하루 화면(라이트)
3. `03-guide-light.png` — 뒷면 탭 연결 단계 안내
4. `04-settings-dark.png` — 설정: 하루 시작 시간·메인 색·화면 모드·소리와 진동
5. `05-setup-dark.png` — 첫 실행: 하루가 시작되는 시간 고르기

2026-11-16 App Store Connect 기준 필수 크기는 6.3형(1179×2556 또는 1206×2622)이다. 6.9형 이미지를 필수 칸에 올리면 ‘파일 크기가 유효하지 않습니다’ 오류가 난다. `marketing-6.3/`은 `marketing/`을 너비 1206으로 Lanczos 축소한 뒤 위아래 1px을 배경색으로 채워 1206×2622로 맞췄다(글자·화면 잘림 없음, 01 시각 확인). 6.3형을 올리면 더 작은 iPhone 화면용은 App Store Connect가 줄여서 쓴다.

## 앱 미리보기 영상 (올리지 않음, 보관용)

- 886×1920, 30fps, 20.0초(Apple 기준 15~30초), 소리 없음, 2.4MB
- 내용: 하루 화면 → 기록 3번(위쪽 토스트) → 오른쪽 밀어 지우기(그라데이션·휴지통) → 설정
- 시뮬레이터 화면 녹화(`xcrun simctl io recordVideo`)를 AVFoundation으로 크기만 바꿈. 홈 화면과 시작 직후 어두운 구간은 잘라 앱 화면만 남겼다(Apple은 앱 밖 화면을 넣지 못하게 한다)
- 녹화용 자동 재생 코드는 임시로만 넣고 커밋하지 않았다
