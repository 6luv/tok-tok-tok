# 심사 메모 (App Review Information › Notes)

App Store Connect의 ‘심사 정보 › 메모’에 붙여 넣는다. 심사 담당자는 영어를 쓰므로 영어 본문을 넣고, 한국어는 확인용이다.

## 영어 (제출용)

TokTokTok is a personal time-stamp app. It saves the current time with one action and groups records by a day boundary the user chooses (for example, a day that starts at 4:00 AM).

No account or login is required. There is no server, no ads and no analytics. All data is stored on the device and is never sent to the developer or any server. It may be included in the user's own iCloud or computer backups.

Privacy policy: the full text is available in the app at Settings (gear icon) > 개인정보와 데이터 > 개인정보처리방침 전문, and at https://toktoktok-nine.vercel.app/privacy/.

How to test in under a minute:
1. On first launch, pick any day start time and tap "이 시간으로 시작" (Start with this time).
2. Tap "현재 시간 기록" (Record current time) at the bottom. A new record appears at the top of the list, with a short sound and one vibration (both can be turned off in Settings > 소리와 진동).
3. Swipe a record to the right to delete it.
4. Open Settings (gear icon) to change the day start time, accent color, light/dark mode, and sound/vibration.

Back Tap (optional, requires a physical device):
The app provides an App Intent, "현재 시간 기록" (Record current time). Users add it to a shortcut in the Shortcuts app and assign that shortcut to Settings > Accessibility > Touch > Back Tap > Triple Tap. The app cannot change this system setting itself; it only guides the user (Settings > 뒷면 탭 연결). Back Tap works only while the screen is on. The in-app button provides the same function without any setup.

The app is in Korean.

## 한국어 (확인용)

TokTokTok은 개인 시각 기록 앱이에요. 한 번의 동작으로 지금 시각을 저장하고, 사용자가 정한 하루 기준(예: 새벽 4시 시작)으로 기록을 묶어 보여 줘요.

계정·로그인이 필요 없고 서버·광고·분석이 없어요. 모든 데이터는 이 기기에 저장되고 개발자나 서버로 보내지 않아요. 사용자의 iCloud·컴퓨터 백업에는 포함될 수 있어요.

개인정보처리방침: 앱 안 설정(톱니) › 개인정보와 데이터 › 개인정보처리방침 전문, 그리고 https://toktoktok-nine.vercel.app/privacy/ 에 전문이 있어요.

1분 안에 확인하는 방법:
1. 처음 실행하면 아무 하루 시작 시간이나 고르고 ‘이 시간으로 시작’을 눌러요.
2. 아래 ‘현재 시간 기록’을 누르면 목록 맨 위에 새 기록이 생기고, 짧은 소리와 진동이 한 번 나요(설정 › 소리와 진동에서 끌 수 있어요).
3. 기록을 오른쪽으로 밀면 지워져요.
4. 톱니 아이콘(설정)에서 하루 시작 시간, 메인 색, 라이트·다크, 소리·진동을 바꿀 수 있어요.

뒷면 탭(선택, 실기기 필요):
앱은 App Intent ‘현재 시간 기록’을 제공해요. 사용자가 단축어 앱에서 이 동작으로 단축어를 만들고, 설정 › 손쉬운 사용 › 터치 › 뒷면 탭 › 세 번 탭에 연결해요. 앱이 이 시스템 설정을 직접 바꾸지는 못하고 안내만 해요(설정 › 뒷면 탭 연결). 뒷면 탭은 화면이 켜져 있을 때만 동작해요. 앱 안 버튼으로도 설정 없이 같은 기능을 쓸 수 있어요.
